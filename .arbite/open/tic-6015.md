## Acceptance criteria
- Every scenario in the examples doc passes as written, with byte-compared stdout and stderr and asserted exit codes.

- Documentation states that non-proxy writes are unattributed drift and that arbite cannot prove who wrote a file.
- Existing regression tests pass or are deliberately updated for a documented safety restriction.
- Scenarios BY1, BY3, all scenarios, both-sink conformance pass exactly as written in the examples doc.

## Validation

Sibling tickets may touch the same files; coordinate edits or work serially until the proxy exists. Record implementation decisions, validation results, observable behaviour and remaining limitations in ticket notes before close.
